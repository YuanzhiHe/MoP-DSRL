\title{Reference Matching for Noise-Space Policy Fine-Tuning}
\begin{highlights}
\item Matching a uniform reference and maximising mode entropy are one objective
\item Cloned policies are never uniform, so the two objectives come apart
\item A total-variation penalty on a mode histogram, with no learned component
\item Beats entropy maximisation on both tasks, by more as the reference skews
\item Matches a learned-skill method using a histogram and one scalar weight
\end{highlights}
