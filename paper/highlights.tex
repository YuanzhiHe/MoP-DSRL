\title{Reference Matching for Noise-Space Policy Fine-Tuning}
\begin{highlights}
\item Matching a uniform reference and maximising mode entropy are one objective
\item Forty cloned policies, none uniform, so the two objectives come apart
\item A total-variation penalty on a mode histogram, with no learned component
\item The gap to entropy maximisation grows with each policy's measured skew
\item Closer to the pretrained behaviour than a discriminator and a skill space
\end{highlights}
